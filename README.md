# Playwright Test Automation Framework

End-to-end UI and API test automation framework built using
Playwright and Python.

## Features

- UI automation with Playwright
- API testing
- Pytest framework
- Page Object Model
- Data-driven testing
- Parallel execution
- Allure reporting
- Accessibility testing
- Performance testing
- Docker support
- GitHub Actions CI/CD

## Tech Stack

Python | Playwright | Pytest | REST API | Docker |
GitHub Actions | Allure | JMeter
